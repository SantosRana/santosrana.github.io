01 / About

Building AI systems that work in the real world

Hi, I'm Santosh, a Machine Learning and AI Systems engineer focused on turning models into practical, reliable applications.

My work has evolved from classical machine learning and landmark-based computer vision into NLP, large language models, retrieval-augmented generation, agentic workflows, and multimodal AI systems.

Recent projects include MediQwen, an offline privacy-first clinical AI assistant built around local inference, RAG, LangGraph workflows, multimodal processing, and deterministic safety guardrails; and ReviewLens, an agentic restaurant-review intelligence platform combining ABSA, external API integration, structured outputs, and evidence validation.

I care about more than model accuracy. I focus on preprocessing, evaluation, latency, grounding, security, failure handling, and the engineering decisions that make AI systems dependable outside the notebook.

Selected work across AI systems, language, and vision

PROJECT 001

MediQwen

An offline, privacy-first multimodal clinical assistant for low-resource and off-grid settings. Powered by Qwen 3.5 on local Ollama inference, and built as a LangGraph finite state machine with BGE scope classification, hybrid medical RAG, four-tier risk triage, and multi-layer safety guardrails.

100% Local Inference
FSM Safety Routing
4 Risk Tiers
Focus: Designed for remote regions with limited clinicians and no internet, such as rural Nepal. Combines deterministic guardrails that run before any LLM call, BGE-based scope gating, multimodal clinical image handling, emergency escalation, and retrieval-grounded responses over a local ChromaDB knowledge base with an optional trusted web fallback.
Qwen 3.5 Ollama LangGraph RAG ChromaDB BGE Embeddings Guardrails Multimodal AI FastAPI Streamlit

ReviewLens

An agentic AI system for Korean restaurant review intelligence that combines Aspect-Based Sentiment Analysis, external API integration, structured LLM outputs, dual-boundary security, and verbatim quote grounding.

100% Evidence Validation
