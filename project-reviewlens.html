ReviewLens

AI-Powered Restaurant Review Analysis System

Project Overview

ReviewLens is an agentic restaurant review intelligence platform that leverages Aspect-Based Sentiment Analysis (ABSA) and Groq LLMs to transform unstructured Naver Blog reviews into structured, evidence-grounded insights. The system decomposes sentiment across core dining aspects (Food, Price, Service, Ambience) and enforces strict verbatim quote validation to eliminate hallucinated summaries for both consumers and restaurant owners.

System Architecture

An overview of the request lifecycle: queries pass through security guardrails and domain routing before executing search tools, Groq batch ABSA extraction, verbatim evidence validation, and state caching.

Key Features

  • Aspect-Based Sentiment Analysis (ABSA) across FOOD, PRICE, SERVICE, and AMBIENCE
  • Dual-Boundary Security Guardrails against prompt injections and malicious review text
  • Domain Intent Routing classifying queries into CASUAL, REVIEW, FOLLOW_UP, or OFF_TOPIC
  • Real-time Naver Blog Search API integration with HTML cleaning and review chunking
  • 100% Verbatim Quote Validation via algorithmic substring matching (Zero Hallucination)
  • In-Memory State Caching (analysis_cache) enabling dynamic side-by-side restaurant comparisons
  • Interactive Streamlit dashboard with bilingual conversational synthesis and structured tables

How It Works

  1. User submits a query or raw custom review text to ReviewLens
  2. Boundary 1 Guardrails inspect and sanitize inputs against injection or jailbreak threats
  3. Domain Guard classifies prompt intent (CASUAL, REVIEW, FOLLOW_UP, OFF_TOPIC)
  4. The agent executes search tools to fetch live review snippets via the Naver Search API
  5. ABSA Orchestrator dispatches batch payloads to Groq API (gpt-oss-120b) with structured JSON schemas
  6. ABSA Output Validator runs substring matching checks to ensure evidence quotes are 100% verbatim
  7. Aspect scores and validated evidence quotes are cached in session memory (analysis_cache)
  8. The agent synthesizes a bilingual English explanation with Markdown comparison tables and Korean quote citations
